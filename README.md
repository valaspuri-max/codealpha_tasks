# 🌐 AI Language Translation Tool

## 📌 CodeAlpha Artificial Intelligence Internship — Task 1

This project is a **Language Translation Tool** developed as part of my Artificial Intelligence internship at **CodeAlpha**.

The application allows users to enter text, select a source language and target language, and translate the text using a translation API.

## 🚀 Features

- 🌍 Multiple language support
- 🔤 Source and target language selection
- 🔄 Real-time text translation
- 📋 Copy translated text
- ⚠️ Error handling for invalid or empty input
- 📱 Mobile-friendly and responsive interface
- 🎨 Clean and simple user interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Translation API
- Bolt.new

## 🔄 How It Works

1. The user enters text into the input box.
2. The user selects the source language.
3. The user selects the target language.
4. The application sends the text to the translation API.
5. The API returns the translated text.
6. The translated result is displayed to the user.
7. The user can copy the translated text using the Copy button.

## 🧪 Testing

The application was tested with multiple language combinations, including:

- English → Hindi
- English → Telugu
- English → Spanish
- English → French
